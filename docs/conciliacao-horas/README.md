# Conciliação de horas — continuidade do trabalho

O objetivo é comparar as horas de ponto do VR Mais com os apontamentos do quadro EG03_MICRO PLANEJAMENTO. Cada sessão Monday pertence ao usuário que iniciou o relógio.

**Comece pelo [contexto para o próximo agente](contexto-para-proximo-agente.md).** Ele reúne decisões finais, hipóteses substituídas, evidências, limites do estudo e próximos passos, sem credenciais ou dados pessoais.

## Ordem de leitura

1. [Contexto para o próximo agente](contexto-para-proximo-agente.md): passagem de trabalho e situação atual.
2. [Plano de produto e estudo](plano-produto-estudo.md): cenário recomendado, regras, interface, fases, fontes e 28 cenários de validação.
3. [Especificação funcional original](especificacao-funcional.md): requisitos e prompts iniciais; interpretar com as atualizações do contexto e do plano.
4. [Manual HTML proposto](manual.html): experiência em laranja e cinza, com dados fictícios; não é uma aplicação implementada.

## Como continuar

A etapa vigente neste chat é planejamento e preparação de arquitetura, sem implementação. As instruções prontas estão na seção 11 do contexto e na seção 14.3 do plano.

Quadro de origem e autoria por start são decisões confirmadas. Tolerância, prazo de lançamento, frequência de atualização e período histórico ainda contêm propostas a validar. Uma instrução posterior explícita do responsável pode mudar a etapa ou o escopo; receber estes documentos não autoriza automaticamente codificação ou alterações em produção.
